--------------------------------------------------------
  ESTRUTURA DO PROJETO
--------------------------------------------------------

  compilador/
  ├── include/
  │   └── tokens.h       <- tipos de token
  ├── src/
  │   └── main.cpp       <- modo arquivo + interativo
  ├── tests/
  │   └── programa.src   <- programa de teste
  ├── lexico.l           <- regras do Flex
  ├── compila.bat        <- script de compilação
  └── Makefile           <- alternativa ao compila.bat


--------------------------------------------------------
  COMO ADICIONAR UM NOVO TOKEN (ex: RG)
--------------------------------------------------------

  Passo 1 — tokens.h:
    Adicione dentro do enum:
    LIT_RG,

  Passo 2 — lexico.l:
    Adicione na area de tokens especiais:
    {DIGITO}{2}"."{DIGITO}{3}"."{DIGITO}{3}"-"{DIGITO} { return (int)TokenType::LIT_RG; }

  Passo 3 — main.cpp:
    Adicione no switch de tokenTypeName():
    case TokenType::LIT_RG: return "LIT_RG";

  Passo 4 — Recompile:
    .\compila.bat
